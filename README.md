# Onam Veg

A ground-up restaurant website redesign with forest green, warm ivory, editorial typography, and original restaurant photography.

## Open

Open `dist/index.html` directly, or run `npm start` and visit http://127.0.0.1:4173. No installation or build step is required.

## Features

- Original logo and 33 menu images downloaded from https://www.onamveg.in/.
- Complete original menu with category browsing and search.
- Dish details, persistent order bag, quantity controls, and WhatsApp handoff.
- Restaurant address, hours, click-to-call and directions.
- Responsive layout and keyboard-accessible dialogs.

Menu prices use the original menu page (which differs from some homepage prices). The restaurant confirms final prices and availability. WhatsApp opens a draft; the visitor sends it. No payment or automatic order submission occurs.

Edit `dist/styles.css`, `dist/index.html`, `dist/app.js`, and `dist/menu-data.js`. Assets live in `dist/assets/`. Fonts are loaded from Google Fonts with local system fallbacks.
